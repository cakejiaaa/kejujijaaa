Catatan Proyek Running Text Arduino

Kemampuan: Arduino Uno, LCD I2C & logika dasar
Contoh Tampilan Running Text
Welcome Callysta Cantik — Di SMA BOASH EXCELLENT
Kode Arduino 
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {
  lcd.init();
  lcd.backlight();
}

void loop() {
  lcd.setCursor(0, 0);
  lcd.print("Welcome Callysta Cantik");
  lcd.setCursor(0, 1);
  lcd.print("Di SMA BOASH EXCELLENT");

  for (int i = 0; i < 6; i++) {
    lcd.scrollDisplayLeft();
    delay(200);
  }
}

Proyek ini berawal dari Mr Salas, tentang bagaimana tulisan bisa berjalan di layar LCD memakai Arduino. Dari situ aku belajar dari Mr Salas, bagaimana menyusun kode sederhana dan mengatur pergeseran teksnya.
